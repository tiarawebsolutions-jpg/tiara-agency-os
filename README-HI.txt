TIARA AGENCY OS — OFFLINE LIBRARY

क्या शामिल है:
- मूल Agency Agents स्रोत से 283 agent instruction files
- आधिकारिक divisions.json के अनुसार 18 विभाग
- ZIP में मिले 330 Markdown दस्तावेज़
- मूल runbooks.json के 4 scenario runbooks और उनकी team rosters
- Agent search, department filters, document library, copy prompt, favorites
- PWA offline cache; Android और desktop browser पर install किया जा सकता है

इस्तेमाल:
1. इस ZIP को Netlify Drop (https://app.netlify.com/drop) पर अपलोड करें।
2. बनी हुई वेबसाइट को पहली बार इंटरनेट के साथ खोलें।
3. Android Chrome: ⋮ > Add to Home screen / Install app.
4. Desktop Chrome/Edge: Install icon या browser menu > Install.
5. Agents tab में agent खोलें, निर्देश कॉपी करें और ChatGPT में पेस्ट करें।

महत्वपूर्ण सीमाएँ:
- यह ऐप एजेंट निर्देशों की offline library है; इसमें AI model शामिल नहीं है।
- ChatGPT में जवाब पाने के लिए इंटरनेट और ChatGPT account/usage limits लागू होंगे।
- कोई paid API key या backend शामिल नहीं है।
- Native installer scripts/IDE integrations को ब्राउज़र में स्वतः चलाना संभव नहीं; उनके दस्तावेज़ Library में रखे गए हैं।
- पहली बार ऐप को online खोलें ताकि service worker assets cache कर सके।
