Tools & Help

How to Use Without API Costs

  1. Choose a specialist in AI Agents.
  2. Tap Copy Instructions.
  3. Open ChatGPT and paste the instructions.
  4. Then describe the task you want done. ChatGPT Free usage limits apply.

Offline Access

Open this app with an internet connection at least once. After that, the app and its downloaded library can be available offline. An internet connection is required to get AI responses from ChatGPT.

Android: In Chrome, tap ⋮ → Add to Home screen / Install app. Desktop: In Chrome or Edge, use the Install icon or choose Install from the menu.
